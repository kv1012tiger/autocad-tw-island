📘 CFG 設置新建圖層程式

LCFG、GCFG、QCFG、DDD 圖層清單工具

✍ Tiger&蘋果爸 · 2024-11-28

原文：CFG 設置新建圖層程式

LCFG 指令：讀取「我的文件」資料夾的 AT_LayerList.cfg，依內容自動建立圖層並設定顏色與線型；檔案不存在時會自動建立預設清單。

GCFG 指令：萃取目前圖檔的所有圖層（名稱、顏色、線型）產生 AT_LayerList.cfg，排除外部參考圖層。

QCFG 指令：開啟 AT_LayerList.cfg 方便編輯。

DDD 指令：快速開啟「我的文件」資料夾。

ACADAdviser 程式放置於 C:\AutoCAD Adviser；ATStruCAD 程式放置於 C:\ATStruCAD\ZLISP，使用 APPLOAD 加入啟動套件。
