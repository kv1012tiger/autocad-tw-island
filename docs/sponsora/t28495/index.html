📘 設置標註專用圖層程式 v3

標註自動放到專用圖層與顏色

✍ Tiger&蘋果爸 · 2024-01-01

原文：設置標註專用圖層程式 v3

標註自動放到專用圖層與顏色。

  • DDF：標註延伸線開關
  • DD1：線端點快速標註
  • DD2：聚合線端點快速標註
  • DD3：線&聚合線端點快速標註
  • DDLI：線性標註
  • DDAL：對齊式標註
  • DDAN：角度標註
  • DDRA：半徑標註
  • DDDI：直徑標註
  • DDBA：基線式標註
  • DDCO：連續式標註
  • DDSet：標註圖層&顏色設置

程式請放置於 C:\AutoCAD Adviser（結構外掛請放 C:\ATStruCAD\ZLISP），使用 APPLOAD 載入。
