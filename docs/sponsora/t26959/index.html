📘 XclipObjects 快速裁剪工具

局部物件轉換、縮放與快速裁切

✍ Tiger&蘋果爸 · 2023-01-01

原文：XclipObjects 快速裁剪工具

局部物件轉換、縮放與快速裁切。

  • XclipCha：多重_局部物件轉換(XcC)選取既有的圖面物件直接轉換(截取刪除邊界以外不需要的
  • XclipMul：多重_局部物件縮放(XcM)多重複選既有的圖面邊界(聚合線或圓)，直接截取刪除邊
  • XclipObj：單一_局部物件縮放(XcO)單一選取既有的圖面邊界(聚合線或圓)，直接截取刪除邊
  • XclipRec：矩形_局部物件縮放(XcR)自行繪製矩形範圍邊界，直接截取刪除邊界以外不需要的物

程式請放置於 C:\AutoCAD Adviser（結構外掛請放 C:\ATStruCAD\ZLISP），使用 APPLOAD 載入。
