📘 ADR 鋼筋混凝土、ADS 鋼結構自動化生成工具

✍ Tiger&蘋果爸 · 2026-08-29

ADR 是一套專為鋼筋混凝土 (RC) 結構平面圖設計開發的全自動化生成工具。

支援參數化生成與現有圖面逆向辨識，主要特色包括：

  1. 支援「單獨選取網格」或「單獨選取柱子」，選柱子自動反推補齊網格。
  2. 選取既有物件後直接「原位生成」，無需指定插入點。
  3. 支援辨識斜向網格角度與偏心柱邊界。
  4. 自動建立 RC 柱圖塊 (含實心填色)，同尺寸共用圖塊定義且不重複繪製既有柱。
  5. 智慧配置大梁、小梁 (支援水平/垂直優先打斷) 與樓板。
  6. 外圍大梁自動切齊柱邊 (可維持軸線等分)。
  7. 自動繪製外圍網格尺寸、柱標註、連續淨空梁間距標註。
  8. 自動統計 RC 柱、大梁、小梁、樓板面積與總長並產生數量報告。

ADS 是一套專為結構工程與鋼結構設計開發的全自動化繪圖系統。

介面或直接選取圖面現有網格/柱位，能一鍵完成：

  1. 柱位建立與自動方向錯開 (0° / 90°)。
  2. 柱軸網格線與外圍尺寸標註自動生成。
  3. 主鋼梁 (大梁) 自動連接、銲接三角形標記自動退縮配置與文字標註。
  4. 次鋼梁 (小梁) X/Y 等分跨配置、圓形銲接標記退縮與文字標註。
  5. 斜撐 (交叉式 / 菱型式) 自動分割與退縮繪製。
  6. 中心線及實體雙線外框自動派發與圖層管理。
