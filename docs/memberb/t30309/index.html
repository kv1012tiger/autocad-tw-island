📘 O2L 魔法分層神器程式

選取物件自動分層，顏色 1～9 輪流

✍ Tiger&蘋果爸 · 2025-10-11

原文：O2L 魔法分層神器程式

想讓 AutoCAD 圖面瞬間井然有序？輸入 O2L 自動分層指令，選取文字、剖面線或圖塊後立刻自動分類，新圖層還會自動套上顏色 1～9 輪流變換，再多的圖面也能瞬間分層清晰、顏色分明。

程式請放置於 D:\LISP程式，使用 APPLOAD 載入。
