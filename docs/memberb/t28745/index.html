原文：匿名圖塊轉換&圖塊分解禁用允許程式

📢匿名圖塊轉換&圖塊分解禁用允許程式_專屬B/贊助A新功能程式說明:1️⃣圖塊分解禁用&允許BlockExpNoAll指令：BKNA全部圖塊設置禁用分解BlockExpYesAll指令：BKYA全部圖塊設置允許分解2️⃣物件轉匿名圖塊Object2AnyBk指令：OAB物件轉匿名圖塊(禁用分解)Object2AnyMI指令：OAM物件轉匿名圖塊陣列(禁用分解)3️⃣一般圖塊&匿名圖塊互轉Block2AnyBK指令：BAB圖塊轉匿名圖塊(禁用分解)Block2AnyMI指令：BAM圖塊轉匿名圖塊陣列(禁用分解)Block2AnyUn指令：BAU轉換更名一般圖塊(允許分解)👇程式掛入方式🛠️自動載入Lsp(Fas)程式 - APPLOAD指令 D:\LISP程式👇匿名圖塊轉換&圖塊分解禁用允許程式下載👇

  • BlockExpNoAll：BKNA全部圖塊設置禁用分解
  • BlockExpYesAll：BKYA全部圖塊設置允許分解
  • Object2AnyBk：OAB物件轉匿名圖塊(禁用分解)
  • Object2AnyMI：OAM物件轉匿名圖塊陣列(禁用分解)
  • Block2AnyBK：BAB圖塊轉匿名圖塊(禁用分解)
  • Block2AnyMI：BAM圖塊轉匿名圖塊陣列(禁用分解)
  • Block2AnyUn：BAU轉換更名一般圖塊(允許分解)

程式請放置於 D:\LISP程式，使用 APPLOAD 載入。
