📘 自動陣列圖塊程式

AAN、AAD、AAXY 三種圖塊自動排列

✍ Tiger&蘋果爸 · 2025-11-30

原文：自動陣列圖塊程式

以前要排圖塊：先算距離，再算數量，然後一顆一顆放。放錯位置？重來。間距不對？重做。矩形邊框慢慢補，到最後眼睛都花了。

現在 AutoCAD 外掛可以幫你排：

  • AAN：你說要放幾顆，它自己平均。
  • AAD：你說間距，它自己算數量。
  • AAXY：你只要放四個角，剩下全部補滿。

程式請放置於 D:\LISP程式，使用 APPLOAD 載入。
