  • Csv2BlockCount（C2BC）：圖塊數量匯出CSV檔
  • Csv2LayerArea（C2A）：自動圖塊座標值匯出圖層CSV檔
  • Csv2LayerLength（C2L）：長度圖層數量匯出CSV檔
  • Csv2LayerLength2（C2L2）：長度圖層數量匯出CSV檔(除2)
  • Csv2TxtCount（C2T）：文字內容數量匯出CSV檔
  • Dwg2LayerObj（D2L）：圖層物件匯出dwg檔

程式請放置於 D:\LISP程式，使用 APPLOAD 載入。
